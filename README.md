# AwgChain

A two hop chain for the AmneziaWG Windows client: apps -> hop 2 -> hop 1 -> ISP.

* `control/`  the awgchain.bat control panel
* `patches/`  the patch scripts applied to the upstream client
* `scripts/`  helper scripts: stress test, MTU probe, leak test, locks
* `fork-sources/`  the Go files of the fork
* `upstream-*/`  the current state of the patched repositories

Upstream: https://github.com/amnezia-vpn/amneziawg-windows-client

No keys and no working configuration files are published here.
